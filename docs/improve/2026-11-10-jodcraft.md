# JOÐcraft: evolve pass, 10 November 2026

Branch `claude/gifted-fermat-t7deyq`, on `origin/main` as of #136. A full cycle with no focus given, so it took up the last pass's own list. Nothing deployed.

## Brief

- **What.** The landing page of a private Paper Minecraft server for eight friends, in Icelandic. Its one job: show the server is alive and let the crew walk into their world. Around it the notice board, a wall per member, play nights with letters, the Myndavél's photos and the owner's panel.
- **Identity.** One evening in a badlands sunset, scrolled into night. Terracotta strata, oak planks, paper slips, lantern glass; three pixel faces; amber only on what can be pressed; no soft edge; motion in the game's whole steps; the game's own UI as the vocabulary.
- **Stack.** Next 16, React 19, plain CSS on OKLCH tokens, Redis and Vercel Blob, vitest, Vercel.
- **Protected.** The sunset hero, the flight, the rail, the rooms over the world, the hotbar, the campfire, every URL and anchor. All intact.

## How it was done

The site was built, run and walked staged at 390 and 1440 px. Two readers audited the client and the server code in parallel, each told to refute its own findings before reporting; every finding below was then read again in the code before it was changed, and each change of logic has a test.

## Fixed

**The server**

- **One address could lock any member out of signing in.** Tries the address limit had already refused still counted toward the account's hourly cap, so 21 requests turned the right password away for an hour, repeatably. A refused try is no longer counted against the account. (`api/crew/auth`; test)
- **`/api/stats` could be made to read exaroton on every request.** The only throttle was the CDN's, which keeps an answer per address asked, so any query string reached the listing and eight files on the key the lantern and the map share. The read is kept a minute in the instance; a failed read is not kept. (`api/stats`; two tests)
- **With mail off, the five-minute job never decided a night.** It read the nights only through the letters. It reads them itself now. (`api/cron/nights`)
- **The splash counted in the wrong number**: "1.231 klukkustundir", "40.321 verur felldar". (`home-data.ts`)
- **Pin ids 3 and 3.5 were both saved as 3.** A pin's id must be whole. (`map.ts`)

**The page**

- **The world went on saying "inni núna" after the server was lost**, with heads and follow buttons from the last list, under a lantern that said it could not reach the server. (`World.tsx`)
- **An old letter's yes to a time that lost stood ready as "Mæti" for the time that won.** Only a yes to the chosen time, or one given before, is filled in. (`PlayNight.tsx`)
- **Turning the sound off cut it** where it was meant to fade: the ramp ran from the start-up's end, long past. (`ambience.ts`)
- **The duel's three-foul ending** ran under the round count at 1440, and the small line hung left of a wide call. "Allt fallið", centred. (`QuickDraw.tsx`, `badlands.css`)
- **A wall's crease on a phone could be a blank button**, and said "1 ákærur". (`crease.ts`; test)
- **The world's birthday line** would have said "eins ára". (`Hero.tsx`)

## New features

**Skjátextar.** With "Vindur og eldur" on, the game's subtitle box at the foot of the screen on the right writes what the site sounds: *Vindur gnauðar*, *Eldur snarkar*, and a line for the item pop, the flint, the duel's hit and foul and the server's chime. Three seconds a line, dimming in four steps. It shows the sound is on when a phone is on silent. Try it: press the sound toggle by the campfire, then foul a round of the duel.

**Fullt hús.** On an evening under way that everyone who said yes has come to (two or more), the fireworks of gamlárskvöld go up over the campfire and the hero's line says *öll 4 komin*. Try it staged: `STAGE=1 STAGE_NIGHT=full SECTIONS=1 node scripts/shots.mjs shots /`.

A first build drew the rockets as a new CSS component; it was thrown out when the canvas fireworks the site already has for New Year's Eve turned out to do the job, so the feature is a rule, a prop and a line of copy.

## Not done

- **Splitting the home's rules out of `badlands.css`.** Measured: inner pages use 17 to 18 kB of its 126 kB (minified). But the home-only rules are interleaved with shared ones that later rules override by order: a mechanical split that provably keeps the cascade moves only about a fifth of the sheet, and anything more needs the sheet reordered by hand with the live map's states (which this sandbox cannot stage) checked on a real deploy. Too risky for its gain here.
- **The flight's camera path out of the first load** (6.4 kB gz): `World.tsx` reads it at first paint to pin the places on frame 0, so loading it later means a first frame without pins. Left.
- **The environment token still signs in after a member sets a password** (`api/crew/auth`). The README calls it a fallback, so this may be meant; it is the owner's call, not changed.
- **Two members lighting a fire for the same evening in the same instant both succeed** (`api/playnight`): the clash check and the write are not one step. Rare with eight people; needs a lock.
- **The hero's "komin" count trails the room's** by up to five minutes: the hero reads what the server noted, the room also reads who is in right now. The fireworks follow the hero's count.
- **Still open from 7 November**: a cloud slab's sliver on a wall at 760 to 1000 px; the postcard's coordinates 12 px too wide at 320 px.
- **Not tested here**: the subtitle box in Safari (it needs the popover API for the top layer and falls back to being drawn in place); the fade on real speakers.
